# Bricks and Beats (Minecraft 26.3, Fabric, Kotlin)

Сборка: `./gradlew build` (нужна Java 25). Готовый мод — `build/libs/bricks_and_beats-1.0.0.jar`.
Нужны Fabric Loader 0.20.1+, Fabric API 0.167.0+26.3, Fabric Language Kotlin.

## Что есть
- 3 зомби-копателя (медленный / средний / быстрый) и яйца призыва для них (вкладка «Яйца призыва»).
  Появляются с киркой от деревянной до алмазной; скорость копания = скорость игрока с этой киркой × множитель.
  Множители лежат в `entity/MinerTier.kt` (0.5 / 1.0 / 1.75), шансы кирок — там же.
- Все мотыги стали оружием (урон/скорость в `HoeWeapons.kt`; плюс компонент `weapon`: −1 прочности за удар, как у меча).
- **mob_griefing**: копатели ломают блоки только при `/gamerule mob_griefing true`. Выключили правило — перестают копать сразу, даже посреди блока.
- 4 зачарования для мотыги (JSON в `data/bricks_and_beats/enchantment`): Жатва, Прополка, Выжигание, Подсечка.

## Общий мозг зомби (`ZombieHive.kt`)
Зомби, хаски, утопленники, зомби-жители и копатели думают вместе (отдельно в каждом измерении):
- общая цель: увидел один — знают все в радиусе 30 блоков;
- память: место, где видели цель, остаётся «шумом» на 10 секунд, рой идёт туда;
- слух: ломание блоков игроком (14), бой с игроком (20), копание зомби (12), взрыв TNT и крипера (48) —
  зомби в радиусе звука идут проверить. Радиусы — константы в начале файла.

## Кирпичи
- Кидаются **ванильные** кирпичи: обычный (`minecraft:brick`) и незерский (`minecraft:nether_brick`). ПКМ — бросок (`BrickThrowing.kt`, событие Fabric `UseItemCallback`).
  Урон игрока 3, зомби 2, пауза 0.5 сек. Шанс 30%, что кирпич не разобьётся и упадёт предметом. Числа — в `entity/ThrownBrick.kt`, `BrickThrowing.kt`.
- Кастомная 3D-модель подменяет ванильную везде (инвентарь, рука, земля, полёт): `assets/minecraft/items/brick.json` и `nether_brick.json`
  ведут на `models/item/brick.json` и `nether_brick.json` (блоки `elements` + `display`), текстуры в `textures/item/`.
  Хочешь убрать подмену модели — удали два файла в `assets/minecraft/items/`, бросок останется.
- Зомби с кирпичами (`ZombieBricks.kt`): 25% новых зомби (ванильные, хаски, утопленники, жители и копатели) появляются с 3–8 кирпичами
  в левой руке (3/4 обычных, 1/4 незерских), кидают в цель с 5–18 блоков (пауза 2.5–4 сек), пока не кончатся; своих не бьют.
  Остатки выпадают при смерти.
